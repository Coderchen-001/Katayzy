## 方法论备注（防复发）

1. properties 是 \uXXXX 转义——裸中文 grep 搜不到，必须解码后再查（本轮再次踩坑一次，已用 Python 解码闭环）。
2. 比对必须先归一化：去尾部快捷键括号（含 `+`，如 `(Ctrl+W)`）、统一省略号、去空白与 `/`。
3. CSV path 尾段是手写缩写，与权威 label 列存在 33 处不一致（如"打开"vs"打开棋谱"）——label 列才是权威，path 仅作定位。
4. 真实树按 label 合并同名词节点（两处"设置"、工具栏"同步"开关 vs 同步菜单），读 real-menu-tree.txt 时需注意。
5. 建议执行 AI 把 feature-inventory.csv 增加一列 `verified_path`（本报告 A/C 类的真实路径），保留原 path 以便 diff 追溯；B 类幽灵条目在 migration_status 标 `no-entry`，IA 冻结下不动入口、只如实记录。
